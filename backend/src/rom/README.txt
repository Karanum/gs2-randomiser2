Place your "Golden Sun - The Lost Age" ROM file (English version only!) in this directory and name it "gs2.gba".
This allows the application to find the file, load it, and use it to generate seeds.

Many memory values are hard-coded based on analysis of the ROM data.
Different versions of the game may have different storage locations for their game data, 
which can cause malformed data to be loaded into the randomiser.
